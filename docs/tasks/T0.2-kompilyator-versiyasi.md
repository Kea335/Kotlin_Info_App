## Problem

`data/KotlinCompiler.kt:29`:

```kotlin
private val VERSIYALAR = listOf("2.1.20", "2.1.0", "2.0.20")
```

Bu üç versiyanın **heç biri** JetBrains xidmətinin elan etdiyi siyahıda yoxdur.
`GET https://api.kotlinlang.org/versions` cavabı (2026-09-13):

```
2.4.20 (latestStable), 2.4.10, 2.4.0, 2.3.21, 2.2.21 (latestCompletion),
2.1.21, 2.0.21, 1.9.25, 1.8.21, 1.7.21, 1.6.21, 1.5.31, 1.4.30, 1.3.72, 1.2.71
```

Server naməlum versiyanı səssizcə ən son stabilə yönləndirir — yoxlanılıb:

```
POST /api/2.1.20/compiler/run  →  println(KotlinVersion.CURRENT)  =  2.4.20
POST /api/2.4.10/compiler/run  →  2.4.10   (mövcud versiya, yönləndirmə yoxdur)
```

Yəni «Yoxla» və Kod meydanı **təsadüfən** işləyir. JetBrains bu yönləndirməni
dayandıran kimi üç ehtiyat versiyanın üçü də rədd olunacaq və kod icrası
tamamilə dayanacaq. Kodda «sınanmış kompilyator versiyaları» şərhi yanıldıcıdır.

Əlavə nəticə: istifadəçi hansı Kotlin versiyasında kod yazdığını bilmir —
məsələn `when` guard sintaksisi 2.1.21-də xəta verir, 2.4.20-də işləyir.

## Həll

### 1. Statik siyahını düzəlt

```kotlin
/**
 * Xidmətin elan etdiyi versiyalar (api.kotlinlang.org/versions).
 * Birincisi tətbiqin öz Kotlin versiyasıdır — dərslərdəki sintaksis ilə
 * icra mühiti eyni olsun deyə. Server 400/404 qaytarsa növbətisi sınanır.
 */
private val EHTIYAT_VERSIYALAR = listOf("2.4.10", "2.4.20", "2.3.21")
```

### 2. Runtime-da siyahını oxu

İlk icra sorğusundan əvvəl `GET /versions`, nəticəni 24 saat keşlə:

```kotlin
@Serializable
private data class ApiVersion(
    val version: String,
    val latestStable: Boolean = false
)

/** Keş köhnədirsə yenilənir; şəbəkə yoxdursa ehtiyat siyahı işlədilir. */
private suspend fun versiyalar(): List<String>
```

Keş `UserPrefs`-də iki açarda: `compiler_versions` (nöqtəli vergüllə ayrılmış)
və `compiler_versions_ts` (epoch ms). Mövcud `xeriteAc` / `xeriteYaz` üslubunda
yaz — zədəli dəyər tətbiqi çökdürməməlidir.

**Seçim qaydası:** tətbiqin öz Kotlin versiyasına ən yaxın mövcud versiya
(major.minor uyğunluğu), yoxdursa `latestStable`.

### 3. Aktiv versiyanı göstər

Kod meydanındakı xəbərdarlıq zolağında və Tənzimləmələrdə:

```
Kompilyator: Kotlin 2.4.10
```

Cavabda yönləndirmə aşkarlansa (istifadə olunan ≠ sorğu edilən) Tənzimləmələrdə
boz qeyd: «Server 2.4.20 versiyasına yönləndirdi».
