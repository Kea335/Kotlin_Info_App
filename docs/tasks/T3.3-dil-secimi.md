# T3.3 — Dil modeli və seçim mexanizmi

| | |
|---|---|
| **Prioritet** | P0 |
| **Təxmin** | 1,5 gün |
| **Asılılıq** | T3.2 |
| **Branch** | `i18n/dil-secimi` |

## Məqsəd

15 dil + «Sistem dili» seçimi; seçim həm **UI resurslarına**, həm **məzmun
qovluğuna** eyni anda təsir etsin və restart-dan sonra qalsın.

## 1. Dil modeli

```kotlin
// data/AppDil.kt
enum class AppDil(
    val teq: String,        // BCP-47: "az", "pt-BR", "zh-CN"
    val ozAdi: String,      // "Azərbaycan", "Português (Brasil)", "简体中文"
    val rtl: Boolean = false
) {
    AZ("az", "Azərbaycan"),
    TR("tr", "Türkçe"),
    EN("en", "English"),
    RU("ru", "Русский"),
    ES("es", "Español"),
    PT_BR("pt-BR", "Português (Brasil)"),
    DE("de", "Deutsch"),
    FR("fr", "Français"),
    AR("ar", "العربية", rtl = true),
    FA("fa", "فارسی", rtl = true),
    HI("hi", "हिन्दी"),
    ID("id", "Bahasa Indonesia"),
    ZH_CN("zh-CN", "简体中文"),
    JA("ja", "日本語"),
    KO("ko", "한국어");

    companion object {
        fun from(teq: String?): AppDil? = entries.firstOrNull { it.teq == teq }
    }
}
```

`ozAdi` **tərcümə olunmur** — hər dil öz adı ilə görünür (istifadəçi başa
düşmədiyi dildəki siyahıda öz dilini tapa bilsin deyə).

## 2. Android resurs qovluqları

| Locale | Qovluq |
|---|---|
| az, tr, en, ru, es, de, fr, ar, fa, hi, ja, ko | `values-az`, `values-tr`, … |
| pt-BR | `values-b+pt+BR` |
| zh-CN | `values-b+zh+Hans` (və ya `values-zh-rCN`) |
| id | `values-b+id` (köhnə kod `in` problemi üçün) |

`res/xml/locales_config.xml`:

```xml
<locale-config xmlns:android="http://schemas.android.com/apk/res/android">
    <locale android:name="az"/>
    <locale android:name="tr"/>
    <!-- … 15 dənə -->
</locale-config>
```

Manifestdə: `<application android:localeConfig="@xml/locales_config" …>`

## 3. Tətbiq səviyyəsində dil dəyişməsi

**Bu addım mövcud quruluşa toxunur — diqqətlə oxu.**

Hazırda `MainActivity : ComponentActivity` və tema
`android:Theme.Material.Light.NoActionBar`-dır. `AppCompatDelegate`-in
per-app locale API-si AppCompat tələb edir:

1. `androidx.appcompat:appcompat:1.7.x` asılılığı
2. `MainActivity : AppCompatActivity`
3. Tema AppCompat ailəsindən: `Theme.AppCompat.DayNight.NoActionBar`
   (Compose `MaterialTheme` onsuz da öz rənglərini işlədir, XML teması yalnız
   pəncərə fonu və sistem zolaqları üçündür — `windowBackground` mövcud
   `KAz.colors.bg` ilə uyğunlaşdırılmalıdır)

Dəyişmə:

```kotlin
fun dilSec(dil: AppDil?) {
    viewModelScope.launch { prefs.dilSec(dil?.teq) }   // null = sistem dili
    AppCompatDelegate.setApplicationLocales(
        if (dil == null) LocaleListCompat.getEmptyLocaleList()
        else LocaleListCompat.forLanguageTags(dil.teq)
    )
}
```

Android 13+ sistem bunu özü saxlayır; 13-dən aşağıda AppCompat DataStore-dakı
seçimi tətbiq edir — ona görə **hər iki yerə yazılır**.

### Alternativ (AppCompat istəmirsənsə)

`attachBaseContext`-də `createConfigurationContext(config)` ilə əl ilə wrapping.
Daha az kod asılılığı, amma Android 13+ sistem menyusunda dil görünmür və
resurs yenilənməsi kövrəkdir. **Tövsiyə: AppCompat yolu.**

## 4. Məzmun tərəfi

```kotlin
class ContentRepository(private val context: Context) {
    @Volatile private var cariDil: String = "az"

    fun dilDeyisdi(teq: String) {
        if (teq == cariDil) return
        cariDil = teq
        temizle()          // bütün keşlər sıfırlanır
    }

    private suspend fun oxu(ad: String): String = withContext(Dispatchers.IO) {
        val yol = "content/$cariDil/$ad"
        val fallback = "content/en/$ad"
        try { context.assets.open(yol) } catch (e: IOException) {
            try { context.assets.open(fallback) } catch (e2: IOException) {
                context.assets.open("content/az/$ad")
            }
        }.bufferedReader().use { it.readText() }
    }
}
```

Dil dəyişəndə `AppViewModel` məzmunu yenidən yükləyir və axtarış motorunu
yeni dil teqi ilə qurur (T0.1-dəki `dilTeqi` parametri buradan gəlir).

## 5. Tərəqqi

Tərəqqi **ID-lərə** bağlıdır (`sintaksis-p-01`), mətnə yox — dil dəyişəndə
toxunulmur. Bunu testlə qıfılla.

## Qəbul kriteriyası

- [ ] 15 dil + «Sistem dili» seçilə bilir
- [ ] Seçim restart-dan sonra qalır
- [ ] Android 13+ sistem tənzimləmələrində tətbiq dil siyahısında görünür
- [ ] Dil dəyişəndə həm UI, həm məzmun eyni anda dəyişir (ekran yenidən qurulur)
- [ ] Tərcüməsi olmayan dildə tətbiq `en`, o da yoxdursa `az` ilə işləyir, çökmür
- [ ] Dil dəyişəndən sonra tərəqqi eynidir (test)
- [ ] Kod redaktorundakı yazı dil dəyişməsində itmir (T2.2 state-i)

## Diqqət

T2.4-də manifestdən `configChanges` silinib — bu **vacibdir**: `uiMode` və
`locale` orada qalsaydı dil dəyişəndə resurslar yenilənməzdi.

`Locale.forLanguageTag("zh-CN")` ilə resurs qovluğu adı (`b+zh+Hans`) fərqlidir —
model teqini resurs qualifier-inə çevirən xəritə lazım ola bilər. Sınaqdan keçir.
