## Məqsəd

Hər push və PR-da test, lint, build və məzmun yoxlaması avtomatik işləsin;
qırmızı CI ilə `main`-ə merge mümkün olmasın.

## 1. Workflow

`.github/workflows/android.yml`:

```yaml
name: Android CI

on:
  push:
    branches: [ main ]
  pull_request:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # gradle-daemon-jvm.properties toolchainVersion=25 tələb edir
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '25'

      - uses: actions/setup-node@v4
        with:
          node-version: '20'

      - uses: gradle/actions/setup-gradle@v4

      - name: Unit testlər
        run: ./gradlew test --stacktrace

      - name: Lint
        run: ./gradlew lint

      - name: Debug build
        run: ./gradlew assembleDebug

      - name: Məzmun yoxlaması
        run: node tools/verify-content.js --assets-only

      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: app-debug
          path: app/build/outputs/apk/debug/app-debug.apk

      - uses: actions/upload-artifact@v4
        if: failure()
        with:
          name: test-reports
          path: app/build/reports/
```

## 2. `verify-content.js` üçün `--assets-only` rejimi

**Problem:** validator saytın `index.html` faylını oxuyur
(`SAYT = process.env.KOTLINAZ_WEB || 'C:/Users/PC-01/Desktop/kotlinweb'`),
CI-da isə sayt repo-su yoxdur — skript birinci addımda çökür.

**Həll:** skriptin ikinci hissəsi (çalışma/quiz bütövlüyü) saytdan asılı deyil.
Bayraq əlavə et:

```js
const YALNIZ_AKTIV = process.argv.includes('--assets-only');
// ...
if (!YALNIZ_AKTIV) {
  // 1–3-cü bölmələr: sayt ilə müqayisə
} else {
  console.log('Yalniz aktivler rejimi — saytla muqayise atlanildi.');
}
// 4-cü bölmə (calismalar/quiz butovlugu) hər iki rejimdə işləyir
```

Çıxış kodu qaydası dəyişmir: problem varsa 2.

## 3. Branch protection

GitHub → Settings → Branches → `main`:
- Require status checks to pass: **build**
- Require branches to be up to date
- (İstəyə bağlı) Require pull request before merging

## Diqqət

**JDK versiyası:** `gradle/gradle-daemon-jvm.properties` daemon üçün JDK 25
tələb edir. CI-da 17 qursan Gradle foojay-dan JDK endirməyə çalışacaq (yavaş və
kövrək). Ya 25 qur (yuxarıdakı variant), ya da həmin faylı sil və layihəni
`java-version: '17'` ilə işlət. Birini seç və README-də qeyd et.

**Keş:** `setup-gradle` konfiqurasiya keşini özü idarə edir; əlavə
`actions/cache` lazım deyil.
