# T5.3 — Bookmark və şəxsi qeydlər

| | |
|---|---|
| **Prioritet** | P1 |
| **Təxmin** | 2 gün |
| **Asılılıq** | T5.1, T3.1 (blok ID-ləri) |
| **Branch** | `feature/bookmark-qeyd` |

## Məqsəd

İstifadəçi dərsi, çalışmanı və ya konkret kod nümunəsini işarələyib sonra
qayıda bilsin; öz sözləri ilə qeyd yaza bilsin.

## Hədəflər

| Tip | ID mənbəyi | Giriş nöqtəsi |
|---|---|---|
| Bölmə | `section.id` | Dərs ekranında üst paneldə ikon |
| Çalışma | `calisma.id` | Çalışma kartında ikon |
| Kod bloku | blok ID (T3.1) | Kod kartının başlıq zolağında ikon |

Kod bloku üçün sabit ID **məhz bu funksiya üçün** lazımdır — mövqeyə bağlı
işarə sayt yenilənəndə başqa koda sürüşərdi.

## Qeydlər

- Hədəfə bağlıdır (`hedefId`), mətn istifadəçinin öz yazısıdır
- **Dildən asılı deyil** — tərcümə olunmur, dil dəyişəndə olduğu kimi qalır
- Redaktə və silmə var; silmə təsdiq soruşur
- Uzunluq limiti yoxdur, amma UI-da 4 sətir göstərilir + «Hamısını göstər»

## Ekran

Yeni route: `Bookmarklar`. İki tab: **İşarələnənlər** / **Qeydlər**.
Filtr çipləri: hamısı / bölmə / çalışma / kod.

Sətirə toxunuş → hədəfə keçid (dərs, çalışma, və ya kodun olduğu dərs).

Giriş nöqtəsi: Tənzimləmələr və Dərslər ekranının yuxarısında ikon.

## Qəbul kriteriyası

- [x] Üç tipdə bookmark əlavə/silmə işləyir
- [x] Qeyd əlavə, redaktə və silmə işləyir (silmə təsdiq soruşur)
- [x] Restart-dan sonra hamısı qalır — Room (T5.1, cihaz testləri)
- [x] Dil dəyişəndə qeyd mətni dəyişmir, bookmark hədəfi düzgün qalır
- [x] Silinmiş hədəf (məzmundan çıxarılmış ID) çökmə yaratmır — sətir atlanır
- [x] Boş hal ekranları var (hər iki tab)
- [x] Mətnlər resources-dadır

## Diqqət

Bookmark ikonu **kod kartının başlıq zolağında** yer tutur — orada artıq
«İşlə», «Meydan», «Kopyala» düymələri var. Dar ekranda sıxışma olmaması üçün
zolağı üfüqi sürüşən et və ya ikonları kiçilt (T5.6-dakı 48 dp qaydası ilə
ziddiyyət yaratmadan — həll: ikonlar eyni qalsın, zolaq sürüşsün).

`Auto Backup` qeydləri yedəkləyir. İstifadəçiyə «qeydlərin cihaz yedəyinə
düşür» məlumatı Tənzimləmələrdə bir sətirlə verilsin.

## Tətbiq qeydi (2026-09-23)

- **Hədəflər** (`ui/isareler/Hedefler.kt`, saf): `hedefXeritesi` — bölmə,
  çalışma (nəzəri sual / praktiki tapşırıq) və iç-içə (callout, kart, tab)
  kod blokları id üzrə; başlıqsız kod bloku ilk dolu sətri ilə. Keçid:
  `Kecid.Ders(bolme, blok)` / `Kecid.Calisma(movzu, calisma)`. Məzmunda
  olmayan hədəfin işarəsi və qeydi atlanır.
- **Giriş nöqtələri:** dərs başlığında qeyd + işarə düymələri və qeyd kartı
  (4 sətir, «Hamısını göstər»); çalışma sayğacının yanında cari çalışmanın
  qeyd + işarə düymələri və qeyd kartı; kod kartının başlıq zolağında işarə
  (yalnız dərsdə — `LocalKodIsaresi`, meydan və çalışma kodunda yoxdur).
  Başlıq zolağında başlıq `weight(1f)` ilə daralır, ikonlar yerində qalır.
- **Ekran** `Yol.Isareler`: «İşarələr · N» / «Qeydlər · N» tabları, tip
  filtri (hamısı / dərs / çalışma / kod), toxunuş → hədəf. Kod blokuna keçid
  `Yol.Ders(id, blok)` — dərs üst səviyyə bloka sürüşür (`ustBlokIndeksi`);
  çalışmaya `Yol.Calisma(id, hedef)` — rejim, filtrsiz indeks, bir dəfə.
  Açılış: Dərslər ekranının üst panelindəki ikon və Tənzimləmələr → Tərəqqi
  («İşarələr və qeydlər bu cihazda saxlanılır və Android yedəyinə düşür»).
- Qeyd dialoqu: boş saxlamaq silir; mövcud qeydi «Sil» təsdiq soruşur.
- Testlər: `IsarelerTest` 5 (hədəflər, atlanma, sürüşmə indeksi, işarə/qeyd
  ViewModel-i, dil dəyişəndə qeyd mətni qalır), `ExerciseViewModelTest` +1.
  Cəmi 310 JVM testi yaşıl. Emulyatorda ekrana baxılmayıb.
