## Problem

1. **Commit olunmamış versiya keçidi.** Working tree-də `libs.versions.toml`
   (AGP 9.3.1 → 9.4.0) və `gradle-wrapper.properties` (Gradle 9.5.0 → 9.6.0)
   dəyişikliyi var; README cədvəli köhnə nömrələri göstərir.
2. **İstifadəsiz asılılıq.** `androidx.webkit` (`app/build.gradle.kts:87`)
   heç yerdə çağırılmır — README özü «WebView işlədilmir» yazır.
3. **Ölü funksiyalar.** `kotlinVisualTransformation` (`KotlinHighlighter.kt:241`),
   `rememberKotlinTransformation` (`:247`) — redaktor `KodRedaktoru.kt`-dəki
   keşlənmiş variantı işlədir. `ContentRepository.section()` çağırılmır.
4. **Əl ilə yazılmış versiya.** `SettingsScreen.kt:269` — `"KotlinAZ · v1.0.0"`.
   AGP 9-da `BuildConfig` defolt söndürülüb, ona görə sabit yazılıb.
5. **LICENSE yoxdur.** Portfolio repo-sunda lisenziya görünməlidir.

## Diqqət

`gradle/gradle-daemon-jvm.properties` faylında `toolchainVersion=25` var —
Gradle daemon-u JDK 25 tələb edir, halbuki `compileOptions` Java 17 hədəfləyir.
Bu özlüyündə problem deyil, amma **CI-da JDK 25 qurulmalıdır** (bax T1.3).
Faylı burada silmə — qərarı T1.3-də ver.
