## Problem — tərcümənin qarşısındakı əsas struktur maneə

`content.json`-dakı blokların **id-si yoxdur**. Onlar yalnız massivdəki mövqe
ilə tanınır:

```kotlin
// LessonDetailScreen.kt:107
itemsIndexed(section.blocks, key = { index, _ -> "b$index" })
```

`build-content.js` isə `content.json`-u hər dəfə saytın `index.html` faylından
**sıfırdan** qurur. Nəticə: sayta bir paraqraf əlavə olunan kimi ondan sonrakı
bütün blokların mövqeyi sürüşür.

Əgər tərcümə faylları mövqeyə bağlansa (`"sintaksis.blocks[7]"`), saytın ilk
kiçik redaktəsi 15 dildəki tərcüməni səhv bloklara yapışdıracaq — səssizcə.
**Ona görə bu task T3.2-dən əvvəl gəlir.**

## Həll

### 1. `build-content.js` hər bloka ID versin

```js
const crypto = require('crypto');

/** Blokun məzmunundan sabit id: dəyişməyən blok həmişə eyni id alır. */
function blokId(sectionId, tip, metn) {
  const h = crypto.createHash('sha1').update(metn).digest('hex').slice(0, 8);
  return `${sectionId}.${tip}.${h}`;
}
```

`metn` — blokun **mətn məzmunu** (spans birləşdirilmiş, kod bloku üçün kodun
özü, cədvəl üçün bütün hüceyrələr). Formatlaşdırma dəyişsə id dəyişməsin deyə
boşluqlar normallaşdırılır.

Eyni bölmədə eyni mətnli iki blok olsa (məsələn iki eyni `<hr>`) sonuna sıra
nömrəsi əlavə olunur: `.2`, `.3`.

İç blokların id-si də olmalıdır (callout / card / tab daxilindəkilər) — onlar
da tərcümə olunur.

### 2. Model

```kotlin
@Serializable @SerialName("p")
data class Paragraph(
    val id: String = "",
    val spans: List<Span> = emptyList(),
    val lead: Boolean = false
) : Block
```

`id` bütün blok tiplərinə əlavə olunur. Defolt `""` — köhnə aktivlər hələ də
parse olunur (`ignoreUnknownKeys` onsuz da açıqdır).

`Block` sealed interfeysinə `val id: String` qoymaq daha təmiz olardı, amma
`data object` variantları (`QuizBlock`, `PlaygroundBlock`, `Divider`) bunu
mümkün etmir — onlar üçün id lazım da deyil (tərcümə olunan mətn yoxdur).

### 3. UI

```kotlin
itemsIndexed(
    items = section.blocks,
    key = { index, blok -> (blok as? IdliBlok)?.id?.ifBlank { null } ?: "b$index" }
)
```

### 4. Sabitlik testi

`tools/test-blok-idleri.js` (və ya T1.2-yə əlavə):
- `content.json`-u iki dəfə qur, id-lər eynidir
- Saytın nüsxəsinə bir paraqraf əlavə et, yenidən qur:
  **mövcud blokların id-si dəyişməyib**, yalnız yeni id əlavə olunub

## Diqqət

**Hash mətndən qurulur, ona görə mətn dəyişsə id dəyişir** — bu bilərəkdəndir:
mətn dəyişibsə tərcümə köhnəlib və yenidən baxılmalıdır. T3.2-dəki validator
belə halları «yeni/köhnəlmiş tərcümə» kimi göstərəcək.

Çalışmaların (`sintaksis-p-01`), quiz suallarının (`quiz-01`) və playground
nümunələrinin (`salam`) **onsuz da sabit id-si var** — onlara toxunma.
