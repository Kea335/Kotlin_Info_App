## Məqsəd

Məzmunu locale üzrə idarə olunan hala gətirmək — **tərcümə yazmadan**.
Bu taskdan sonra `en` üçün boş skelet mövcud olacaq və validator 0 % göstərəcək.

## Quruluş

```
localization/
├── POLICY.md              T4.0-da yazılır
├── glossary.json          T4.0-da yazılır
├── en/
│   ├── content.json       yalnız tərcümə olunan sahələr, ID ilə açarlanmış
│   ├── exercises.json
│   ├── quiz.json
│   ├── playground.json
│   └── strings.xml → app/src/main/res/values-en/ (T3.4)
├── tr/ …
└── …

app/src/main/assets/content/
├── az/   { content, exercises, quiz, playground }.json   ← saytdan, baza
├── en/   ← build-locale.js tərəfindən yaradılır
└── …
```

**Baza (`az`) saytdan qurulmağa davam edir** — mövcud boru xətti dəyişmir,
yalnız hədəf qovluq `assets/` → `assets/content/az/` olur.

## Overlay formatı

Tərcümə faylı tam sənədin surəti deyil, yalnız **dəyişən sahələrin** xəritəsidir:

```json
{
  "_meta": { "locale": "en", "base": "az", "updated": "2026-10-01" },
  "sections": {
    "sintaksis": {
      "title": "Basic syntax",
      "heading": "Basic syntax",
      "kicker": "Section 04",
      "blocks": {
        "sintaksis.p.3f9a12c0": { "spans": [ { "k": "t", "v": "Kotlin's syntax is…" } ] },
        "sintaksis.code.9b21ee40": { "title": "First program" }
      }
    }
  }
}
```

Kod blokunda **yalnız `title`** tərcümə olunur; `code` və `output` bazadan gəlir
(bax T4.0 siyasəti).

## Alətlər

### `tools/build-locale.js`

```
node tools/build-locale.js en
node tools/build-locale.js --all
```

Bazanı oxuyur, overlay-i ID üzrə tətbiq edir, `assets/content/en/` yazır.
Çatışmayan sahə bazadan qalır və hesabatda `fallback` kimi sayılır.

### `tools/validate-locales.js`

```
node tools/validate-locales.js            # bütün dillər
node tools/validate-locales.js en --json  # CI üçün
```

Yoxlayır:
- **Struktur eyniliyi:** hər locale-də eyni bölmə ID-ləri, eyni blok ID-ləri,
  eyni çalışma/quiz ID-ləri
- **Texniki sahələrin sabitliyi:** `a` (cavab indeksi), `opts.size`, `level`,
  `index`, `special`, `sectionId` — locale-lər arasında **fərqli ola bilməz**
- **Tərcümə keyfiyyəti:** boş sətir, bazadakı mətnin eynisi (tərcümə olunmayıb),
  dublikat açar, `%1$s` kimi format nişanlarının qorunması
- **Faiz:** hər locale üçün `tərcümə olunmuş sahə / ümumi sahə`

Çıxış:

```
locale  UI      dərslər   çalışmalar  quiz   ümumi
az      100%    100%      100%        100%   100%
en       42%     18%        0%          0%    12%
```

Problem varsa çıxış kodu 2 (CI-da build dayanır — yalnız `az` üçün;
digər dillər üçün T4.7-dəki qapı işləyir).

### `tools/new-locale.js`

```
node tools/new-locale.js en
```

Bazadan boş skelet overlay yaradır (bütün ID-lər, boş dəyərlər) — tərcüməçi
faylı sıfırdan yazmasın.

## Diqqət

**Cavab indeksi (`a`) tərcümədə heç vaxt dəyişməməlidir.** Variantların sırası
da eyni qalmalıdır — tərcüməçi variantları «daha məntiqli» sıraya düzsə düzgün
cavab səhv olur. Validator bunu tuta bilmir (mətn dəyişib), ona görə POLICY-də
açıq yazılmalı və QA-da yoxlanmalıdır.

`playground.json`-da yalnız `label` tərcümə olunur, `code` yox.
