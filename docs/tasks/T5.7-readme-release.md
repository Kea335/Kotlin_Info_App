## Release axını

`docs/RELEASE.md`:

1. `main` yaşıldır, release qapısı siyahısı keçib (`docs/tasks/RELEASE-GATE.md`)
2. `versionCode` və `versionName` artırılır (bir commit)
3. Teq: `v1.2.0`
4. `./gradlew assembleRelease` (imzalı)
5. GitHub Release yaradılır: notes + `app-release.apk`
6. Notes şablonu:

```markdown

### Yeni
- Türk və rus dilləri (UI + 32 dərs + 1250 çalışma + test)

### Düzəlişlər
- …

### Texniki
- …
```
