## Problem

`AppViewModel.axtar()` həm indeksi, həm sorğunu `lowercase()` ilə kiçildir.
Kotlin-in `lowercase()` funksiyası `Locale.ROOT` işlədir və Azərbaycan
əlifbası üçün yanlış nəticə verir:

```
"İstifadəçi".lowercase()               → "i̇stifadəçi"  (11 simvol: i + U+0307)
"İstifadəçi".lowercase(Locale("az"))   → "istifadəçi"   (10 simvol)

index.contains("istifadəçi")   // ROOT ilə qurulmuş indeksdə → false
```

İstifadəçi klaviaturada adi `i` yazır, indeksdə isə `i` + birləşən nöqtə var —
ona görə `İ` ilə başlayan heç bir söz tapılmır. Axtarış indeksində 85 ədəd `İ`
var; «İstisnalar» və «İdiomlar» bölmə başlıqları birbaşa təsirlənir.
Eyni problem `I` → `ı` çevrilməsində də var (ROOT `I` hərfini `i` edir).

**Kodda:** `ui/AppViewModel.kt:114` (indeks qurulur), `ui/AppViewModel.kt:176` (sorğu).

## Həll

Axtarışı ViewModel-dən ayır — həm düzəliş, həm T1.1 testi, həm də T3.5-dəki
dil-üzrə qaydalar üçün lazımdır.

1. Yeni fayl: `data/AxtarisMotoru.kt`

```kotlin
package az.kotlinaz.app.data

import az.kotlinaz.app.data.model.SearchDoc
import java.util.Locale

/**
 * Oflayn axtarış. Saf sinifdir — Context və Compose asılılığı yoxdur,
 * ona görə birbaşa unit testdən çağırıla bilər.
 *
 * Kiçik hərfə çevirmə DİL ÜZRƏ aparılır: Azərbaycan və türk dillərində
 * Locale.ROOT İ hərfini i + U+0307 kimi yazır və axtarış sınır.
 */
class AxtarisMotoru(docs: List<SearchDoc>, dilTeqi: String = "az") {

    private val locale: Locale = Locale.forLanguageTag(dilTeqi)

    private fun kicilt(s: String): String = s.lowercase(locale)

    private data class Sened(
        val doc: SearchDoc,
        val basliqKicik: String,
        val metnKicik: String
    )

    private val indeks: List<Sened> =
        docs.map { Sened(it, kicilt(it.title), kicilt(it.text)) }

    fun axtar(sorgu: String): List<SearchNetice> {
        val q = kicilt(sorgu.trim())
        if (q.length < 2) return emptyList()
        // mövcud AppViewModel.axtar() gövdəsi olduğu kimi buraya köçür
    }
}
```

2. `SearchNetice` data class-ını `AppViewModel.kt`-dən `AxtarisMotoru.kt`-yə köçür.

3. `AppViewModel`-də `kicikIndeks` sahəsini və `axtar()` gövdəsini sil:

```kotlin
private var axtarisMotoru: AxtarisMotoru? = null

// init blokunda, sənədlər oxunandan sonra:
axtarisMotoru = AxtarisMotoru(_searchDocs.value, dilTeqi = "az")

fun axtar(sorgu: String): List<SearchNetice> =
    axtarisMotoru?.axtar(sorgu).orEmpty()
```

`dilTeqi` hələlik sabit az-dır; T3.3-də seçilmiş dildən gələcək.
