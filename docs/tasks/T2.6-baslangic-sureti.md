## Problem

`AppViewModel.init` beş aktivi **ardıcıl** oxuyur (`AppViewModel.kt:106–110`):

```kotlin
_sections.value   = repo.sections()        // 184 KB
_topics.value     = repo.exercises().topics // 547 KB  ← ən böyüyü
_quiz.value       = repo.quiz().questions   //   7 KB
_presets.value    = repo.playground().presets //  4 KB
_searchDocs.value = repo.searchIndex().docs   // 120 KB
```

Hamısı bitməyincə `hazir = false` qalır və ekranda fırlanğıc görünür.
Halbuki ilk ekrana (Dərslər) yalnız `content.json` lazımdır — 547 KB-lıq
çalışma bankı istifadəçi «Çalışmalar» tabına toxunana qədər gözləyə bilər.

Əlavə: `ContentRepository`-də **tək** `Mutex` bütün keşləri qoruyur, ona görə
müstəqil aktivlər paralel oxuna bilmir.

## Həll

1. Hər keş üçün ayrı kilid:

```kotlin
private val contentKilidi = Mutex()
private val exercisesKilidi = Mutex()
// …
```

2. `init` blokunu iki mərhələyə böl:

```kotlin
init {
    viewModelScope.launch {
        try {
            _sections.value = repo.sections()
            _hazir.value = true                    // ← ekran açılır
        } catch (e: Exception) { … }
    }
    viewModelScope.launch {
        try {
            // paralel, ekranı bloklamadan
            val ex = async { repo.exercises().topics }
            val qz = async { repo.quiz().questions }
            val pg = async { repo.playground().presets }
            _topics.value = ex.await()
            _quiz.value = qz.await()
            _presets.value = pg.await()
        } catch (e: Exception) { … }
    }
}
```

3. Axtarış indeksi (T3.5-dən sonra runtime-da qurulacaq) da ikinci mərhələdə
   və `Dispatchers.Default`-da.

4. Ekranların boş-state davranışını yoxla: `topics` hələ boş ikən Çalışmalar
   ekranı açılırsa fırlanğıc göstərməlidir, boş siyahı yox.

## Diqqət

`tereqqi` axını `combine(sections, topics, hellEdilmis, oxunanBolmeler)` ilə
qurulub — `topics` gec gəlsə də özü yenilənəcək. Yəni ilk saniyədə Dərslər
ekranında tərəqqi 0 görünə bilər, sonra dolacaq. Bu qəbuledilən davranışdır,
amma «0 %» yanıb-sönməsin deyə `topics.isEmpty()` halında tərəqqi kartını
skeleton kimi göstərməyi düşün.
