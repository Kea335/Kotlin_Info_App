# T3.6 — RTL dəstəyi (ərəb və fars)

| | |
|---|---|
| **Prioritet** | P0 |
| **Təxmin** | 1 gün |
| **Asılılıq** | T3.3 |
| **Branch** | `i18n/rtl` |

## Problem

`AndroidManifest.xml:14`:

```xml
android:supportsRtl="false"
```

Ərəb və fars dilləri seçiləndə UI soldan-sağa qalır — düymələr, ikonlar və
sürüşmə istiqaməti tərs görünür.

## Addımlar

### 1. RTL-i aç

```xml
android:supportsRtl="true"
```

### 2. Layout auditi

Kodda yerləşmə əsasən `padding(horizontal = …)` və `Arrangement` ilə qurulub —
bunlar RTL-ə **avtomatik uyğunlaşır**. Yoxlanmalı yerlər:

- `padding(start = …)` / `end = …` doğrudur; `left` / `right` varsa dəyişdir
- `TableView` — sabit sütun enləri və üfüqi sürüşmə (sağdan başlamalıdır)
- `TimelineView` — şaquli xətt sola bağlıdır, `start`-a keçməlidir
- `SertSetri`, `Zolaq` — `fillMaxWidth(faiz)` RTL-də sağdan dolmalıdır
- `BolmeSetri` — nömrə sütunu (`width(28.dp)`)

İkonlar onsuz da `Icons.AutoMirrored.*` işlədir — düzgündür.

### 3. Kod həmişə LTR qalmalıdır

Kotlin kodu, konsol çıxışı və gözlənilən nəticə RTL kontekstdə oxunmaz hala
düşür (mötərizələr tərs görünür). Məcburi LTR:

```kotlin
CompositionLocalProvider(LocalLayoutDirection provides LayoutDirection.Ltr) {
    CodeCard(...)      // dərslərdəki kod blokları
    KodRedaktoru(...)  // redaktor
    KonsolMetni(...)   // nəticə panelləri
    DemoCode(...)      // çalışma və quiz kodu
}
```

Yerlər: `CodeCard.kt`, `KodRedaktoru.kt`, `ExercisePlayerScreen.kt`
(gözlənilən nəticə + konsol), `PlaygroundScreen.kt`, `DemoScaffold.kt`.

### 4. Yoxlama

Tərcümə hazır olmadan yoxlamaq üçün:

```bash
adb shell settings put system system_locales ar-XB
# və ya Developer options → "Force RTL layout direction"
```

Ekran-ekran gəz: Dərslər, Dərs (cədvəl + timeline + kod), Çalışmalar (nəzəri
variantlar + praktiki redaktor), Test, Meydan, Axtarış, Tənzimləmələr.

## Qəbul kriteriyası

- [ ] `supportsRtl="true"`
- [ ] RTL rejimində alt menyu, TopAppBar və geri ikonu güzgülənir
- [ ] Kod blokları, redaktor və konsol çıxışı LTR qalır
- [ ] Cədvəllər sağdan sürüşür və kəsilmir
- [ ] Timeline xətti düzgün tərəfdədir
- [ ] Tərəqqi zolaqları düzgün istiqamətdə dolur
- [ ] Qarışıq sətirlərdə (ərəb mətn + `val x = 5`) BiDi pozğunluğu yoxdur
- [ ] Screenshot-lar PR-a əlavə olunub

## Diqqət

RTL-i açmaq **bütün dillərə** təsir edir: LTR dillərdə heç nə dəyişməməlidir,
amma səhv `left`/`right` istifadəsi varsa indi üzə çıxacaq. Açandan sonra
azərbaycanca da bir dəfə gəz.

Ərəb/fars mətnlərdə rəqəmlər (٥ vs 5) — məzmunda Avropa rəqəmləri saxlanılır,
kod nümunələri ilə uyğun olsun deyə. Bunu POLICY-də qeyd et (T4.0).
