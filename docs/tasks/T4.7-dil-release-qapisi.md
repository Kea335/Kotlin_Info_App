# T4.7 — Dil üzrə release qapısı

| | |
|---|---|
| **Prioritet** | P0 |
| **Təxmin** | 0,5 gün |
| **Asılılıq** | T3.2, T3.3 |
| **Branch** | `i18n/release-qapisi` |

## Problem

GPT sənədinin qaydası: «Release yalnız translation validator **bütün dillər**
üçün 100 % nəticə verdikdə hazırlanmalıdır».

Bu qayda tətbiqi aylarla dondurur: 15 dilin hamısı bitənə qədər nə `en`, nə `tr`
istifadəçiyə çatmır, üstəlik bu müddətdə düzəldilən buglar da buraxılmır.

## Həll — qapı dilə tətbiq olunur, release-ə yox

Yarımçıq dil **istifadəçiyə görünmür**, amma kodu və faylları repo-da qalır və
release-i bloklamır.

### 1. Build vaxtı hesabat

`validate-locales.js --json` çıxışından Gradle tapşırığı
`assets/locales_status.json` yaradır:

```json
{
  "generated": "2026-11-02",
  "locales": {
    "az": { "percent": 100, "visible": true },
    "en": { "percent": 100, "visible": true },
    "tr": { "percent":  64, "visible": false }
  }
}
```

Gradle-da:

```kotlin
val dilStatusu by tasks.registering(Exec::class) {
    commandLine("node", "tools/validate-locales.js", "--json",
                "--out", "app/src/main/assets/locales_status.json")
}
tasks.named("preBuild") { dependsOn(dilStatusu) }
```

> Node CI-da onsuz da qurulub (T1.3). Lokal maşında node yoxdursa tapşırıq
> xəbərdarlıqla atlanmalıdır (`isIgnoreExitValue`), build sınmasın.

### 2. Tətbiqdə istifadə

```kotlin
/** Yalnız 100 % tamamlanmış dillər seçim siyahısında görünür. */
val gorunenDiller: List<AppDil> =
    AppDil.entries.filter { status[it.teq]?.visible == true }
```

Tənzimləmələrdəki dil siyahısı bu siyahıdan qurulur. Yarımçıq dilə keçid yolu
yoxdur — yəni istifadəçi yarımçıq tərcümə görmür.

**Debug build-də** bütün dillər görünsün (tərcüməçi öz işini yoxlaya bilsin):

```kotlin
val gorunenDiller = if (BuildConfig.DEBUG) AppDil.entries else filtrlenmis
```

### 3. Astana

100 % tələb olunur, çünki fallback mexanizmi (T3.3) istifadəçiyə **qarışıq dil**
göstərir — bir paraqraf ingiliscə, biri azərbaycanca. Bu, yarımçıq dildən də pisdir.

İstisna: `az` heç vaxt gizlədilmir (baza dildir).

## Qəbul kriteriyası

- [ ] `locales_status.json` build vaxtı yaranır
- [ ] 100 %-dən aşağı dil release build-də siyahıda görünmür
- [ ] Debug build-də bütün dillər görünür
- [ ] Dil 100 %-ə çatanda **kod dəyişikliyi olmadan** siyahıda peyda olur
- [ ] `az` həmişə görünür
- [ ] Node olmayan maşında build sınmır
- [ ] Yarımçıq dillərin faylları APK-ya düşmür (və ya ölçü büdcəsində sayılır)

## Diqqət

Tərcümə olunmamış dilin fayllarını APK-ya qoymamaq üçün `sourceSets`-də
`assets.exclude` işlədilə bilər — amma bu, `locales_status.json`-dan asılı
dinamik siyahıdır, Gradle konfiqurasiya vaxtında hesablanmalıdır. Sadə variant:
`build-locale.js --all` yalnız 100 % dillər üçün `assets/content/<locale>/`
yaratsın, qalanları `localization/` qovluğunda qalsın (APK-ya düşmür).
Bu variant həm ölçünü, həm mürəkkəbliyi azaldır — **tövsiyə olunan budur**.
