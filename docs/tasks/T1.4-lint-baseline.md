## Məqsəd

Android Lint-i CI-da məcburi et, amma mövcud xəbərdarlıqlar işi bloklamasın:
köhnələri baseline-a al, **yeniləri** build-i sındırsın.

## Addımlar

1. `app/build.gradle.kts`:

```kotlin
android {
    lint {
        baseline = file("lint-baseline.xml")
        abortOnError = true
        warningsAsErrors = false
        checkDependencies = true
    }
}
```

2. Baseline-ı yarat və commit et:

```bash
./gradlew lint
git add app/lint-baseline.xml
```

3. Baseline-dakı xəbərdarlıqları oxu və hansının real olduğunu qeyd et.
   Gözlənilənlər: istifadəsiz resurs, `UnusedMaterial3ScaffoldPaddingParameter`,
   `AutoboxingStateCreation`, `contentDescription` çatışmazlığı.
   Ciddi olanları T5.6-ya (əlçatanlıq) köçür, qalanları baseline-da saxla.

## Diqqət

Lint Compose-dakı **hardcoded mətnləri tutmur** — `Text("Növbəti")` heç bir
qayda ilə işarələnmir (`HardcodedText` yalnız XML üçündür). T3.4-də bunun üçün
ayrıca grep qaydası əlavə olunacaq; baseline onu əvəz etmir.

Başlanğıc vəziyyət: `./gradlew lint` → 1 xəta, 19 xəbərdarlıq.

**Xəbərdarlıqların bölgüsü:**

| 3 | `ModifierParameter` (`DemoChip`, `DemoNote`, `DemoToggleRow`) | **Düzəldildi** — `modifier` ilk optional parametr edildi; bütün çağırışlar adlı arqumentlə olduğundan davranış dəyişmir. |

Nəticə: **baseline boşdur** — planda gözlənilən `contentDescription` və
`UnusedMaterial3ScaffoldPaddingParameter` tapıntıları bu kodda yoxdur; T5.6-ya
köçürüləcək ciddi maddə çıxmadı.

**Plandan fərq:** `warningsAsErrors = true` (planda `false` idi). Qəbul
kriteriyası «yeni xəbərdarlıq build-i sındırır» deyir; `false` ilə yalnız
xətalar sındırardı. Baseline boş və vaxta bağlı qaydalar söndürülmüş
olduğundan `true` təhlükəsizdir.

**Yoxlama:** müvəqqəti `Uri.parse(...)` çağırışı olan fayl əlavə edildi →
`Lint found 1 error … [UseKtx]`, build dayandı; fayl silindi → «Lint found no
errors or warnings». 147 test yaşıl, `assembleDebug` keçir.

**Baseline-ı yeniləmək** (yalnız bilərəkdən, PR-da izahla):
`./gradlew updateLintBaseline`.
