## Məqsəd

Android Lint-i CI-da məcburi et, amma mövcud xəbərdarlıqlar işi bloklamasın:
köhnələri baseline-a al, **yeniləri** build-i sındırsın.

## Addımlar

1. `app/build.gradle.kts`:

```kotlin
android {
    lint {
        baseline = file("lint-baseline.xml")
        abortOnError = true
        warningsAsErrors = false
        checkDependencies = true
    }
}
```

2. Baseline-ı yarat və commit et:

```bash
./gradlew lint
git add app/lint-baseline.xml
```

3. Baseline-dakı xəbərdarlıqları oxu və hansının real olduğunu qeyd et.
   Gözlənilənlər: istifadəsiz resurs, `UnusedMaterial3ScaffoldPaddingParameter`,
   `AutoboxingStateCreation`, `contentDescription` çatışmazlığı.
   Ciddi olanları T5.6-ya (əlçatanlıq) köçür, qalanları baseline-da saxla.

## Qəbul kriteriyası

- [ ] `./gradlew lint` CI-da keçir
- [ ] `lint-baseline.xml` commit olunub
- [ ] Qəsdən əlavə edilmiş yeni xəbərdarlıq build-i sındırır
- [ ] Baseline-dakı ciddi maddələr ayrıca qeyd olunub

## Diqqət

Lint Compose-dakı **hardcoded mətnləri tutmur** — `Text("Növbəti")` heç bir
qayda ilə işarələnmir (`HardcodedText` yalnız XML üçündür). T3.4-də bunun üçün
ayrıca grep qaydası əlavə olunacaq; baseline onu əvəz etmir.
