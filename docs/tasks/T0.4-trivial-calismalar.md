## Problem

16 praktiki çalışmada `starter` kodu `hell` (model həll) ilə eynidir.
İstifadəçi heç nə yazmadan «Yoxla» basır, nəticə uyğun gəlir və çalışma həll
edilmiş sayılır — tərəqqi qazanılır, öyrənmə olmur.

```
funksiyalar-p-25          lambda-p-09               scope-funksiyalari-p-05
scope-funksiyalari-p-07   scope-funksiyalari-p-16   scope-funksiyalari-p-25
miras-p-21                miras-p-22                genislenmeler-p-20
genislenmeler-p-21        istisnalar-p-02           delegatlar-p-03
delegatlar-p-08           delegatlar-p-23           coroutines-p-13
coroutines-p-14
```

Nümunə — `funksiyalar-p-25`, tapşırıq «üzv metodun genişlənmədən üstün
olduğunu göstər», starter isə artıq tam işləyən proqramdır:

```kotlin
class A { fun cap() = println("uzv metod") }
fun A.cap() = println("genislenme")
fun main() { A().cap() }
```

**Tərcümədən əvvəl düzəldilməlidir** — əks halda səhv 15 dildə çoxalır.

## Addımlar

1. Mənbədə düzəlt. Çalışmalar `Kotlin_Info_Web` repo-sundakı `js/exercises.js`
   faylındadır. Starter-i yarımçıq hala gətir:

```kotlin
// funksiyalar-p-25 üçün nümunə
class A {
    fun cap() = println("uzv metod")
}

// Eyni adlı genişlənmə yaz və A().cap() çağır — hansı işləyəcək?
```

Qayda: starter tapşırığın **quruluşunu** verir, **cavabını** yox. Çıxışı yaradan
sətir (adətən `println`) istifadəçiyə qalmalıdır.

2. Aktivləri yenidən qur:

```bash
node tools/build-content.js
node tools/verify-content.js
```

3. `tools/verify-content.js`-ə qalıcı qayda (praktiki çalışmalar dövrünün içinə):

```js
if (x.starter && x.hell && x.starter.trim() === x.hell.trim()) {
  exProblem.push(x.id + ': baslangic kodu hell ile eynidir');
}
```

`main`, sabit dəyərlər) qalır, nəticəni yaradan sətir (`println`, lambda
gövdəsi, `by lazy` bloku, `apply`/`let` çağırışı, `try`-`catch`) şərhlə

yaz», «Sablon isledib cap et» kimi). `gozlenilen`, `hell`, `tapsiriq`,
`ipucu` sahələrinə toxunulmayıb — köhnə və yeni `exercises.json` sahə-sahə
tutuşdurulub: yalnız 16 `starter` fərqlidir.

16 problem göstərir, yenilərlə 0.

geri qaytarır (yeni qayda bunu 16 problemlə dərhal göstərəcək).
