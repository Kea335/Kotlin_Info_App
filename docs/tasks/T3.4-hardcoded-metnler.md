# T3.4 — Bütün hardcoded mətnləri resources-a çıxar

| | |
|---|---|
| **Prioritet** | P0 |
| **Təxmin** | 2 gün |
| **Asılılıq** | T3.3 |
| **Branch** | `i18n/strings` |

## Problem

`res/values/strings.xml`-də **bir** sətir var:

```xml
<string name="app_name">KotlinAZ</string>
```

Qalan hər şey Kotlin kodundadır — 68 birbaşa literal + çoxsətirli birləşmələr:

| Yer | Nümunə |
|---|---|
| `AppRoot.kt` | alt menyu etiketləri, başlıqlar, «Geri», «Axtarış» |
| `SettingsScreen.kt` | bütün bölmə adları, izahlar, dialoq mətnləri |
| `ExercisePlayerScreen.kt` | «Yoxla», «İpucu», «Cavab», «Sıfırla», oflayn izahı |
| `QuizScreen.kt` | rejim izahları, rəy mətnləri, «Düzgün cavab: A» |
| `PlaygroundScreen.kt` | xəbərdarlıq zolağı, nəticə panelləri |
| `LessonsScreen.kt`, `LessonDetailScreen.kt` | mənimsəmə kartı, səviyyə şərtləri |
| `BlockRenderer.kt` | quiz/meydan aksiya kartlarının mətnləri |
| `DemoHost.kt` | 6 nümayişin bütün izahları (ən çox mətn burada) |

Əlavə olaraq **etiketlər data qatındakı enum-lardadır**:

```kotlin
Level(val id: String, val label: String)          // Models.kt:262
ThemeMode(val id: String, val label: String)      // UserPrefs.kt:156
QuizRejimi(val id, val label, …) + val izah       // QuizScreen.kt:62
Rejim(val etiket: String)                         // ExercisePlayerScreen.kt:64
```

## Addımlar

### 1. Literal-ları çıxar

Ad qaydası: `<ekran>_<məqsəd>`, məsələn `quiz_netice_mukemmel`,
`calisma_duyme_yoxla`, `meydan_oflayn_izah`.

Say və format üçün parametr:

```xml
<string name="calisma_sayqac">Çalışma %1$d / %2$d</string>
<string name="quiz_duzgun_cavab">Düzgün cavab: %1$s</string>
<plurals name="bolme_sayi">
    <item quantity="one">%d bölmə</item>
    <item quantity="other">%d bölmə</item>
</plurals>
```

> Rus, ərəb, polyak dillərində `plurals` **məcburidir** — `"$n bölmə"` sətir
> birləşməsi orada səhv nəticə verir.

### 2. Enum-ları `@StringRes`-ə keçir

```kotlin
enum class Level(val id: String, @StringRes val labelRes: Int) {
    JUNIOR("junior", R.string.seviyye_junior),
    MIDDLE("middle", R.string.seviyye_middle),
    SENIOR("senior", R.string.seviyye_senior);
}
```

Çağırış yerində: `stringResource(lv.labelRes)`.

`data/` qatı `R`-dən asılı olur — bu qəbuledilən kompromisdir (alternativ:
`ui/` qatında `Level.label(): String` genişlənməsi, `data/` təmiz qalır.
**Tövsiyə: genişlənmə variantı**, çünki `data/` testlərində Android resursu
lazım olmur).

```kotlin
// ui/Etiketler.kt
@Composable fun Level.etiket(): String = stringResource(when (this) {
    Level.JUNIOR -> R.string.seviyye_junior
    …
})
```

### 3. `contentDescription`-lar

Dekorativ ikonlarda `null` qalır, mənalılarda `stringResource`. T5.6-da
əlçatanlıq auditi bunu yenidən yoxlayacaq.

### 4. CI qaydası

Android Lint Compose-dakı `Text("…")` literal-larını **tutmur**
(`HardcodedText` yalnız XML üçündür). Ona görə `.github/workflows/android.yml`-ə:

```yaml
- name: Hardcoded mətn yoxlaması
  run: |
    if grep -rnE '(Text\(|text = )"[^"]{2,}"' app/src/main/java \
         --include=*.kt | grep -v '@Preview' | grep -v '// i18n-ignore'; then
      echo "::error::Kotlin faylında hardcoded UI mətni var"
      exit 1
    fi
```

İstisna lazım olan yerlərdə (`"Main.kt"` fayl adı, `"Kotlin"` kod kartı başlığı)
sətrin sonuna `// i18n-ignore` şərhi.

### 5. `values-en/strings.xml`

`en` tərcüməsi T4.1-də tam yazılacaq, amma skeleti burada yarat ki, dil
seçiləndə tətbiq işləsin.

## Qəbul kriteriyası

- [ ] CI grep qaydası 0 nəticə verir
- [ ] `values/strings.xml`-də ≥ 200 sətir var
- [ ] Bütün enum etiketləri resources-dan gəlir
- [ ] Sayğaclar `%1$d` formatı və ya `plurals` işlədir (sətir birləşməsi yox)
- [ ] `en` seçiləndə tətbiqdə azərbaycanca mətn qalmır (skelet doldurulandan sonra)
- [ ] Ekranların görünüşü dəyişməyib

## Diqqət

**Ən çox mətn `DemoHost.kt`-dədir** (768 sətir, 6 nümayiş). Onu ayrıca kiçik
PR-a ayırmaq daha rahatdır.

Uzun mətnlərdə sətir birləşməsindən (`"a" + "b"`) qaç — tərcüməçi tam cümləni
görməlidir. XML-də `\n` ilə yaz.
