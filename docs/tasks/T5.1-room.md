## Niyə indi, əvvəl yox

GPT sənədi Room-u Sprint 2-də (Task 8) təklif edir. Hazırkı data — id çoxluqları
(`Set<String>`) və bir neçə `Int` — DataStore-a **tam yaraşır**; Room orada
əlavə mürəkkəblikdən başqa heç nə vermir.

Room yalnız bu taskdan sonra gələn funksiyalar üçün lazımdır: səhv cavabların
tarixçəsi, qeydlər, quiz turlarının tarixi, günlük fəallıq. Ona görə Sprint 5-ə
keçirilib.

**Miqrasiya tələb olunmur** — mövcud DataStore datası yerində qalır.

## Sxem

```kotlin
@Entity(tableName = "sehv_cavab")
data class SehvCavabEntity(
    @PrimaryKey val sualId: String,
    val say: Int,
    val ardicilDuzgun: Int,      // 2-yə çatanda «mənimsənildi»
    val sonTarix: Long
)

@Entity(tableName = "bookmark")
data class BookmarkEntity(
    @PrimaryKey val hedefId: String,   // bölmə / çalışma / blok id-si (T3.1)
    val tip: String,                   // "bolme" | "calisma" | "kod"
    val tarix: Long
)

@Entity(tableName = "qeyd")
data class QeydEntity(
    @PrimaryKey val hedefId: String,
    val metn: String,
    val yenilenib: Long
)

@Entity(tableName = "quiz_turu")
data class QuizTuruEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val rejim: String,
    val bal: Int,
    val umumi: Int,
    val tarix: Long
)

@Entity(tableName = "gunluk_fealiyyet")
data class GunlukFealiyyetEntity(
    @PrimaryKey val tarix: String,     // "2026-11-02"
    val hellSayi: Int
)
```

## Repository sərhədi

DAO-lar birbaşa ViewModel-ə verilmir:

```kotlin
interface OyrenmeRepository {

    suspend fun duzgunQeydEt(sualId: String)
    fun bookmarklar(): Flow<List<Bookmark>>

```

`AppContainer`-ə əlavə olunur (T2.1).

## Qəbul kriteriyası

- [ ] 5 entity, DAO-lar və `KotlinAzDatabase` (version = 1) hazırdır
- [ ] `schemas/1.json` commit olunub
- [ ] `OyrenmeRepository` interfeysi və real implementasiyası var
- [ ] DAO testləri (in-memory database) yaşıl
- [ ] Mövcud DataStore datası toxunulmayıb, tərəqqi itməyib
- [ ] APK ölçüsündəki artım qeyd olunub (Room ≈ 300–400 KB)

## Diqqət

`allowMainThreadQueries` **işlədilməməlidir**. Bütün oxumalar `Flow`,
yazılar `suspend`.

`Auto Backup` açıqdır (`allowBackup="true"`) — Room faylı avtomatik yedəklənir.
Bu istənilən davranışdır; `backup_rules.xml` ilə dəqiqləşdirməyi düşün.
