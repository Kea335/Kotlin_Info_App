## Niyə indi, əvvəl yox

GPT sənədi Room-u Sprint 2-də (Task 8) təklif edir. Hazırkı data — id çoxluqları
(`Set<String>`) və bir neçə `Int` — DataStore-a **tam yaraşır**; Room orada
əlavə mürəkkəblikdən başqa heç nə vermir.

Room yalnız bu taskdan sonra gələn funksiyalar üçün lazımdır: səhv cavabların
tarixçəsi, qeydlər, quiz turlarının tarixi, günlük fəallıq. Ona görə Sprint 5-ə
keçirilib.

**Miqrasiya tələb olunmur** — mövcud DataStore datası yerində qalır.

## Diqqət

`allowMainThreadQueries` **işlədilməməlidir**. Bütün oxumalar `Flow`,
yazılar `suspend`.

`Auto Backup` açıqdır (`allowBackup="true"`) — Room faylı avtomatik yedəklənir.
Bu istənilən davranışdır; `backup_rules.xml` ilə dəqiqləşdirməyi düşün.

## Tətbiq qeydi (2026-09-23)

- Versiyalar: Room 2.8.5, KSP 2.3.12 (KSP2 — Kotlin 2.4.10 və AGP 9-un
  daxili Kotlin-i ilə işləyir), Room Gradle plagini (`room { schemaDirectory }`).
- `data/oyrenme/KotlinAzDatabase.kt` — 5 entity + 5 DAO. `gunluk_fealiyyet`
  artımı `INSERT OR IGNORE` + `UPDATE` tranzaksiyada: minSdk 24-ün SQLite-ı
  (3.9) `ON CONFLICT DO UPDATE` bilmir. `@Upsert` Room-un özünündür, köhnə
  SQLite-da da işləyir.
- `data/oyrenme/OyrenmeRepository.kt` — domen modelləri, interfeys,
  `RoomOyrenmeRepository` (oxu-dəyiş-yaz `withTransaction`-da), saf qayda
  `sehvYenile()` (T5.2-nin «2 ardıcıl düzgün → mənimsənilib» qaydası; sətir
  silinmir) və `gunTarixi()` (`java.time` minSdk 24-də yoxdur). Saat
  konstruktorla gəlir.
- `AppContainer.oyrenme` — baza `lazy`, başlanğıcı yavaşlatmır.
- **Testlər:** JVM — `SehvQaydasiTest` (7); cihaz — `OyrenmeRepositoryCihazTest`
  (7, in-memory Room). JVM unit testində Room-un Android variantı (və
  bundled SQLite-ın Android native-i) işləmir, Robolectric API 37-ni
  dəstəkləmir — ona görə DAO testi `androidTest`-dədir və CI-a
  `cihaz-testleri` job-u (android-emulator-runner, API 34, KVM) əlavə olundu.
- Yedək: `databases/kotlinaz.db` `backup_rules.xml`-ə görə yedəklənir (yalnız
  kompilyator keşi çıxarılıb) — istənilən davranış.
