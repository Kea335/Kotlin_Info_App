## Məqsəd

«Nəyi növbəti öyrənim?» sualına avtomatik cavab. Hazırda 32 bölmə qruplara
bölünüb, amma aralarındakı **asılılıq** heç yerdə yazılmayıb — yeni istifadəçi
`generics` bölməsini `funksiyalar`-dan əvvəl aça bilər.

## 1. Asılılıq qrafı

`content.json`-da bölmə səviyyəsində yeni sahə:

```json
{
  "id": "lambda",
  "requires": ["funksiyalar", "kolleksiyalar"]
}
```

Qrafı `build-content.js`-də sabit cədvəldən oxu (`tools/path.json`) — saytın
HTML-ində belə məlumat yoxdur, əl ilə qurulmalıdır.

Təklif olunan əsas zəncir:

```
sintaksis → deyisenler → operatorlar → sertler → dovrler
    → funksiyalar → kolleksiyalar → null-safety
    → lambda → scope-funksiyalari → genislenmeler
    → oop → miras → xususi-sinifler
    → generics → delegatlar → istisnalar
    → coroutines → test
    → android / multiplatform / backend  (paralel, hər biri coroutines-dən sonra)
```

`giris`, `tarixce`, `qurasdirma`, `resurslar`, `java-muqayise`, `idiomlar`
asılılıqsızdır.

## 2. Tövsiyə funksiyası — saf

```kotlin
data class YolVeziyyeti(
    val bolmeId: String,
    val hal: Hal            // KILIDLI | ACIQ | TAMAMLANIB
)

fun novbetiAddim(
    sections: List<Section>,
    qraf: Map<String, List<String>>,
    tereqqi: Tereqqi
): Tovsiye
```

Qayda: bölmə **açıqdır**, əgər bütün `requires` bölmələri tamamlanıbsa
(`BolmeTereqqisi.tamamlandi`). Tövsiyə = ilk açıq və tamamlanmamış bölmə;
onunla birlikdə həmin bölmənin ilk həll edilməmiş çalışması.

## 3. UI

- **Dərslər ekranı:** hər sətirdə vəziyyət nişanı — kilidli (boz + kilid ikonu),
  açıq, tamamlanıb (mövcud ✓)
- **Tövsiyə kartı:** mövcud «Davam et» kartı genişlənir — son bölmə yoxdursa
  tövsiyə göstərilir: «Növbəti: Lambda və HOF · 25 çalışma»
- **Kilidli bölmə** açıla bilər (blok deyil), amma yuxarıda xəbərdarlıq:
  «Bu mövzu üçün əvvəlcə *Funksiyalar* bölməsini tamamlamaq tövsiyə olunur»

> Sərt kilid **qoyma** — istifadəçi istədiyi mövzunu oxuya bilməlidir;
> tövsiyə istiqamət verir, qadağa qoymur.

## Qəbul kriteriyası

- [ ] `tools/path.json` qrafı var, bütün ID-lər mövcud bölmələrə uyğundur (validator)
- [ ] Qrafda dövr (cycle) yoxdur — test bunu yoxlayır
- [ ] `novbetiAddim` saf funksiyadır və testlidir
- [ ] Yeni istifadəçiyə `sintaksis` tövsiyə olunur
- [ ] Bölmə tamamlananda tövsiyə növbətiyə keçir
- [ ] Kilidli bölmə açıla bilir, xəbərdarlıq göstərilir
- [ ] Mətnlər resources-dadır

## Diqqət

Qraf `content.json`-a düşdüyü üçün **tərcümə oluna bilən sahə deyil** —
`requires` texniki sahədir, validator onun bütün dillərdə eyni olmasını
yoxlamalıdır (T3.2 qaydası).
