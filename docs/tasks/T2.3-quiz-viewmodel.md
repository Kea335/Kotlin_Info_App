## Problem

Testin bütün vəziyyəti `remember` ilə kompozisiyadadır (`QuizScreen.kt:265–290`):

```kotlin
var tur by remember(rejim) { mutableIntStateOf(0) }
val suallar = remember(hovuz, tur) { hovuz.shuffled().take(QUIZ_SUAL_SAYI) }
var index  by remember(rejim, tur) { mutableIntStateOf(0) }
var bal    by remember(rejim, tur) { mutableIntStateOf(0) }
```

İstifadəçi 12-ci sualda ikən tətbiq arxa planda öldürülsə (Android üçün adi hal)
qayıdanda tur tamamilə sıfırlanır: yeni suallar, bal 0. 15 sualın 12-si itir.

Əlavə: `hovuz.shuffled()` hər dəfə yeni dəst qaytarır, ona görə **seed saxlamaq
kifayət etmir** — hovuz özü (məzmun yüklənməsi, dil dəyişməsi) dəyişə bilər.

## Həll

```kotlin
class QuizViewModel(
    private val prefs: UserPrefs,
    private val state: SavedStateHandle
) : ViewModel() {

    /** Seçilmiş suallar ID siyahısı kimi saxlanılır — shuffle nəticəsi, seed yox. */
    private var sualIdleri: List<String>
        get() = state["sual_idleri"] ?: emptyList()
        set(v) { state["sual_idleri"] = ArrayList(v) }

    private var rejimId: String? by state.delegate("rejim")
    private var index: Int by state.delegate("index", 0)
    private var bal: Int by state.delegate("bal", 0)
    private var secim: Int? by state.delegate("secim")
    private var bitdi: Boolean by state.delegate("bitdi", false)

    /** Səhv cavab verilən suallar — T5.2 «Səhvlərim» üçün toplanır. */
    private val sehvler = mutableListOf<String>()

    fun turaBasla(rejim: QuizRejimi, hovuz: List<QuizQuestion>) { … }
    fun cavabla(variant: Int) { … }
    fun novbeti() { … }
    fun yenidenBasla() { … }
}
```

`SavedStateHandle`-da yalnız primitiv və `ArrayList<String>` saxlanılır
(Bundle-a yazıla bilən tiplər). Suallar hovuzdan ID ilə tapılır; ID artıq
hovuzda yoxdursa (məzmun dəyişib) tur təmiz başlayır.

Nəticə yazılması (`onBitdi`) `bitdi` false→true keçidində **bir dəfə** qalmalıdır —
mövcud `LaunchedEffect(bitdi)` məntiqi ViewModel-ə köçür, `if (bitdi) return`
qorunması ilə.
