## Məqsəd

Öyrənmə tərəqqisini bir ekranda rəqəm və vizualla göstərmək. Hazırda bu
məlumat Tənzimləmələrin «Tərəqqi» bölməsinə sıxışdırılıb və yalnız sayğaclardır.

## Hesablama — saf funksiya

```kotlin
// data/Statistika.kt
data class Statistika(
    val seviyye: Level,
    val dersler: Say,                     // tamamlanan / ümumi
    val calismalar: Say,
    val seviyyeUzre: Map<Level, Say>,
    val quizTarixcesi: List<QuizTuru>,
    val son7Gun: List<GunlukFealiyyet>,
    val son30Gun: List<GunlukFealiyyet>,
    val streak: Int,                      // ardıcıl fəal gün
    val enUzunStreak: Int
)

fun statistikaHesabla(
    tereqqi: Tereqqi,
    turlar: List<QuizTuru>,
    fealiyyet: List<GunlukFealiyyet>,
    bugun: LocalDate
): Statistika
```

Funksiya **saf** olmalıdır — `bugun` parametr kimi verilir ki, streak testləri
sabit tarixlə yazılsın.

Streak qaydası: bugün və ya dünən fəallıq varsa zəncir davam edir; iki gün
boşluqda sıfırlanır. Gün sərhədi cihazın öz zona vaxtı ilə.

## Ekran

Yeni route: `Statistika`. Bölmələr:

1. **Səviyyə kartı** — mövcud `SeviyyeKarti` buraya köçür (Dərslər ekranında
   qalmağı da olar, təkrarlanmasın deyə birini seç)
2. **Sayğaclar** — dərslər, çalışmalar, Junior/Middle/Senior faizləri
3. **Fəallıq** — son 30 günün sütun qrafiki (Compose `Canvas`, kitabxana lazım deyil)
4. **Quiz tarixçəsi** — son 10 tur: rejim, bal, tarix; rekord vurğulanır
5. **Streak** — cari və ən uzun

Tənzimləmələrdəki «Tərəqqi» bölməsi bu ekrana keçidlə əvəzlənir.

## Qəbul kriteriyası

- [ ] `statistikaHesabla` saf funksiyadır və testlidir (streak sərhəd halları daxil)
- [ ] Ekran real datadan qurulur
- [ ] Fəallıq qrafiki boş datada da düzgün görünür (hamısı sıfır)
- [ ] Quiz turu bitəndə tarixçəyə yazılır
- [ ] Çalışma həll ediləndə günlük fəallıq artır
- [ ] Bütün mətnlər resources-dadır, rəqəm formatı `plurals` ilə
- [ ] Qaranlıq və işıqlı temada qrafik oxunur

## Diqqət

Günlük fəallıq **çalışma həlli** ilə yazılır (`hellSayi`). Dərs oxumaq da
sayılsın istəyirsənsə, ayrıca sütun əlavə et — amma «oxudum» təsdiqi yalnız
çalışmasız bölmələrdə var, ona görə göstərici yanıldıcı ola bilər.

Qrafik üçün kitabxana **əlavə etmə** — 30 sütun `Canvas`-da 30 sətir koddur,
tətbiqin oflayn və yüngül olma prinsipinə uyğundur.
