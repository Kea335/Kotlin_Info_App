## Məqsəd

Tərcümə başlamazdan **əvvəl** qaydaları yazmaq. Hər tərcümə tapşırığı bu iki
fayl ilə başlayacaq; AI tərcüməsində onlar prompt-un məcburi hissəsidir.

## 2. `localization/POLICY.md`

Məcburi qaydalar:

### Tərcümə OLUNMUR
- Kotlin açar sözləri: `fun`, `val`, `var`, `class`, `when`, `if`, `for`, `suspend`…
- Stdlib / API / framework adları: `listOf`, `StateFlow`, `Activity`, `Composable`
- Sinif, funksiya, dəyişən **identifikatorları** kod nümunələrində
- Sabit ID-lər: bölmə, blok, çalışma, quiz, preset
- Cavab indeksi (`a`) və variantların **sırası**
- `level`, `index`, `special`, `sectionId` və digər texniki sahələr

### Tərcümə OLUNUR
- Tapşırıq mətni, ipucu, izah, sual, variantların **mətni**
- Başlıq, alt başlıq, kicker, callout başlığı, kart başlığı, tab etiketi
- Kod bloklarının **başlığı** (`title`), kodun özü yox
- Kod içindəki **şərhlər** (`// İstifadəçinin yaşını yoxlayırıq`)
- UI sətirləri (`strings.xml`)

### String literal-lar — əsas qayda

Kod içindəki mətn literal-ları **defolt olaraq dəyişmir**:

```kotlin
// AZ və EN variantında eyni qalır:
println("Salam, Kotlin!")
```

Səbəb: `gozlenilen` nəticə, `hell` (model həll) və `starter` bir-birindən
asılıdır. Literal dəyişsə üçü də eyni anda dəyişməlidir — 625 çalışma × 14 dil
= 8 750 sinxronlaşma nöqtəsi. Bu riski **sıfırlayırıq**.

İstisna: dərsin məqsədi məhz mətnlə işləməkdirsə (məsələn `uppercase()`
nümunəsi), çalışmaya bayraq qoyulur:

```json
{ "id": "metnler-p-07", "localizedIo": true }
```

Belə çalışmalarda `starter`, `hell` və `gozlenilen` **birlikdə** tərcümə olunur,
validator isə üçünün də overlay-də olmasını tələb edir.

### Rəqəmlər və formatlar
- Kod nümunələrində Avropa rəqəmləri (5, 10) — ərəb/fars daxil
- Mətndə tarix/say formatı dilin öz qaydası ilə
- `%1$d`, `%2$s` nişanları **olduğu kimi** qalır, sırası dəyişə bilər

## 3. AI tərcümə prompt şablonu

`localization/PROMPT.md` — hazır şablon:

```
Sən KotlinAZ öyrənmə tətbiqi üçün <DİL> tərcüməçisisən.
Aşağıdakı POLICY və GLOSSARY qaydalarına tam əməl et.
Sənə JSON overlay parçası verilir; YALNIZ dəyərləri tərcümə et, açarlara toxunma.
Kod bloklarında yalnız şərhləri tərcümə et.
Variantların sırasını dəyişmə.
<POLICY mətni>
<GLOSSARY parçası>
<JSON parçası>
```

## 4. Validator inteqrasiyası

`validate-locales.js`-ə glossary yoxlaması:
- Qadağan siyahısındakı söz tərcümə olunubsa xəbərdarlıq
  (məsələn `ViewModel` → «Görünüş modeli»)
- Glossary-də təsdiqlənmiş qarşılıq varsa, fərqli variant işlədilibsə xəbərdarlıq

## Qəbul kriteriyası

- [ ] `glossary.json` ≥ 20 termin × 15 dil
- [ ] `POLICY.md` yuxarıdakı bütün bölmələri əhatə edir
- [ ] `PROMPT.md` hazırdır və bir dildə sınaqdan keçirilib
- [ ] Validator glossary qaydalarını yoxlayır
- [ ] `localizedIo` bayrağı modeldə və validatorda dəstəklənir

## Diqqət

Glossary-ni **bir nəfər** təsdiqləməlidir. 15 dildə qarşılıqları AI ilə
yaratmaq olar, amma az/tr/en/ru üçün insan baxışı vacibdir — bu dördü digər
tərcümələrin pivotu olacaq.
