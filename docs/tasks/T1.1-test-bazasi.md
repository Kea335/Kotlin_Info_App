## Məqsəd

Böyük refaktordan (Sprint 2) və localization-dan (Sprint 3) əvvəl hazırkı
davranışı testlə qıfıllamaq. Tətbiqdə test üçün ən uyğun kod artıq saf
funksiyalardadır — Android asılılığı yoxdur, birbaşa JVM testindən çağırılır.

## 1. Qurulum

`gradle/libs.versions.toml`:

```toml
[versions]
junit = "4.13.2"
coroutinesTest = "1.10.2"

[libraries]
junit = { group = "junit", name = "junit", version.ref = "junit" }
kotlinx-coroutines-test = { group = "org.jetbrains.kotlinx", name = "kotlinx-coroutines-test", version.ref = "coroutinesTest" }
```

`app/build.gradle.kts`:

```kotlin
android {
    testOptions {
        unitTests {
            isIncludeAndroidResources = false
        }
    }
    sourceSets {
        // Aktivləri unit testdən oxumaq üçün (T1.2)
        getByName("test") {
            resources.srcDir("src/main/assets")
        }
    }
}

dependencies {
    testImplementation(libs.junit)
    testImplementation(kotlin("test"))
    testImplementation(libs.kotlinx.coroutines.test)
}
```

Qovluq: `app/src/test/java/az/kotlinaz/app/…`

> AGP 9-da Kotlin dəstəyi daxilidir — `kotlin-android` plagini əlavə etmək lazım deyil.

## 2. Yazılacaq testlər

### `data/TereqqiTest.kt`
- Junior → Middle: `onSeviyye` = Junior, 80 % çalışma **və** 30 % dərs tələb olunur;
  yalnız biri ödənəndə səviyyə qalxmır
- Middle → Senior: 80 % Middle çalışma + 60 % dərs
- Boş bank (`topics = []`) → səviyyə Junior, `faiz = 0`, çökmə yoxdur
- Çalışması olmayan bölmə: yalnız `oxunanlar` ilə tamamlanır (`calismasiz = true`)
- Naməlum `level` dəyəri (`"expert"`) → `Level.JUNIOR` sayılır
- `sectionId` JSON-da yoxdursa mövzunun öz `id`-si işlədilir

### `data/NormallasdirTest.kt` (`neticeniNormallasdir`)
- `"a\r\nb"` → `"a\nb"`
- Sağdakı boşluqlar atılır: `"a   \nb  "` → `"a\nb"`
- Kənar boş sətirlər atılır, **ortadakı qorunur**: `"\n\na\n\nb\n\n"` → `"a\n\nb"`
- `null` və `""` → `""`
- Yalnız boşluqdan ibarət mətn → `""`

### `editor/TamamlamaTest.kt`
- `prefiksArali`: sətir başı, boşluqdan sonra, rəqəmlə başlayan söz (`12ab` → null)
- Mətn içində (`"pri`) və şərh içində (`// pri`) təklif verilmir
- `tekliflerTap("pri", 3)`: `print` və `println` var, `print` öndədir
- `tekliflerTap("va", 2)`: `val`, `var` → `vararg`-dan qabaq
- `tamamlamaniTetbiqEt`: mötərizəli funksiyada kursor mötərizənin içində
  (`kursorGeri = 1`), şablonda gövdənin içində
- Maksimum 12 təklif

### `highlight/HighlightTest.kt`
- Rənglənmiş mətnin **uzunluğu girişlə eynidir** (OffsetMapping.Identity şərti)
- Raw string (`"""…"""`) tam bir parça kimi
- Şablon ifadəsi `$ad` və `${x.y}` ayrıca rənglənir
- İç-içə blok şərh `/* /* */ */` düzgün bağlanır
- Qaçırılmış dırnaq `"a\"b"` mətni vaxtından əvvəl bitirmir

### `data/UserPrefsCodecTest.kt` (`xeriteAc` / `xeriteYaz`)
- `"junior=12;middle=9"` → `{junior=12, middle=9}`
- Zədəli: `"a=;b=x;c=3"` → yalnız `{c=3}`
- `null` və `""` → boş xəritə
- Gediş-gəliş: `xeriteAc(xeriteYaz(m)) == m`

### `ui/QuizHovuzTest.kt` (`hovuzlariQur`)
- Səviyyə rejimləri yalnız öz səviyyəsinin nəzəri çalışmalarını alır
- Qarışıq = `quiz.json` sualları + bütün bank
- Bank sualının id-si `q-` önlüyü ilə gəlir və quiz.json id-ləri ilə toqquşmur

### `data/AxtarisMotoruTest.kt` (T0.1-dən)
- «istisna» → «İstisnalar» tapılır (İ/ı reqressiya testi)
- «ışıq» və «işıq» eyni nəticə
- Başlıqda tapılan mətndə tapılandan öndə
- Bir hərflik sorğu → boş
- Parça (`snippet`) tapılan sözün ətrafından kəsilir, `…` düzgün qoyulur

Testlər **davranışı olduğu kimi** qıfıllamalıdır — bu mərhələdə davranış

Planlanan dəyişikliklərdən əlavə:

- `xeriteAc`/`xeriteYaz` (`UserPrefs.kt`) və `hovuzlariQur` (`QuizScreen.kt`)
  `private` → `internal` — test eyni moduldan çağıra bilsin. Davranış dəyişmir.
- `kotlin("test")` əvəzinə kataloqda `kotlin-test-junit` — AGP 9-un daxili
  Kotlin-i ilə versiyanı özü tapmır, açıq `version.ref = "kotlin"` lazımdır.
- Compose `AnnotatedString`/`TextFieldValue`/`Color` saf JVM-də işləyir —
  rəngləyici və tamamlama testləri Robolectric-siz keçir.

Test yazarkən davranış səhvi tapılmadı. Bir dəqiqləşdirmə: lambda təklifi
(`forEach { }`, `kursorGeri = 2`) kursoru `{`-dən dərhal sonra, boşluqdan
əvvəl qoyur — testdə olduğu kimi qıfıllanıb.
