## Niyə əvvəlcə `en`

1. **Pivot rolu.** Sonrakı 13 dil ingiliscədən tərcümə olunacaq —
   azərbaycancadan birbaşa tərcümə edə bilən tərcüməçi/model az tapılır.
2. **Auditor rolu.** İngilis versiyası oxunanda məzmundakı qeyri-dəqiqliklər
   üzə çıxır (AZ mətndə gözdən qaçanlar).
3. **Bazar.** Tək `az + en` ilə tətbiq artıq qlobal olur.

## İş axını

1. `node tools/new-locale.js en` — skelet
2. Hissə-hissə tərcümə (hər hissə ayrıca commit):
   - `strings.xml` (UI) → tətbiq artıq ingiliscə açılır
   - Dərs başlıqları + kicker + callout başlıqları
   - Dərs mətni (bölmə-bölmə, 32 commit və ya qrup-qrup 8 commit)
   - Nəzəri çalışmalar (mövzu-mövzu, 25 commit)
   - Praktiki çalışmalar (mövzu-mövzu)
   - Quiz + playground + demo
3. Hər hissədən sonra: `node tools/build-locale.js en && node tools/validate-locales.js en`
4. T4.6 kompilyasiya yoxlaması
