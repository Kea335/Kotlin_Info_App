# T4.6 — Kod nümunələrinin kompilyasiya yoxlaması

| | |
|---|---|
| **Prioritet** | P0 |
| **Təxmin** | 1 gün |
| **Asılılıq** | T0.2, T3.2 |
| **Branch** | `ci/kod-yoxlamasi` |

## Problem

Tətbiqdə **769 kod nümunəsi** var: 144 dərs kod bloku (nəticəsi ilə birlikdə)
və 625 praktiki çalışmanın model həlli. Heç biri avtomatik yoxlanmır.

İki risk:

1. **İndi:** model həll `gozlenilen` nəticəni verməyə bilər — istifadəçi «Cavab»
   düyməsi ilə həlli yükləyir, «Yoxla» basır və **düzgün cavab səhv çıxır**.
2. **Tərcümədən sonra:** şərh tərcüməsi kodu sındıra bilər (dırnaq, `*/`,
   qaçırılmamış simvol), `localizedIo` çalışmalarında isə `gozlenilen` ilə
   `hell` sinxronluğu poza bilər.

## Həll

`tools/check-code.js`:

```
node tools/check-code.js az            # bir dil
node tools/check-code.js --all         # bütün dillər
node tools/check-code.js az --only-changed   # yalnız hash-i dəyişənlər
```

Nə edir:

1. `assets/content/<locale>/` qovluğundan bütün kod nümunələrini toplayır:
   - `content.json` → `code` blokları (`code` + `output`)
   - `exercises.json` → `hell` (+ `gozlenilen`)
2. Hər nümunənin SHA-1 hash-ini `tools/.code-cache.json` ilə tutuşdurur —
   dəyişməyənlər atlanır
3. Qalanları JetBrains kompilyator API-yə göndərir (T0.2-dəki versiya seçimi ilə)
4. Çıxışı `neticeniNormallasdir` qaydası ilə gözlənilənlə müqayisə edir
   (Kotlin-dəki funksiyanın JS qarşılığı — **eyni məntiq olmalıdır**)
5. Hesabat verir və uğurluları keşə yazır

```
KotlinAZ kod yoxlamasi — locale: az
  Kod bloklari      144 / 144 ok
  Model helller     623 / 625 ok
  ! lambda-p-14  : gozlenilen "15" , alinan "16"
  ! coroutines-p-07 : Kompilyasiya xetasi (Setir 4: unresolved reference)
```

### Rate limit

Xidmət ictimaidir — ardıcıl 769 sorğu qəbuledilməzdir:
- Sorğular arasında 300–500 ms gözləmə
- Paralellik ən çoxu 2
- Bir keçid ≈ 10–15 dəqiqə (keşsiz)
- **Nightly** işləyir, hər push-da yox

### CI

`.github/workflows/kod-yoxlamasi.yml`:

```yaml
on:
  schedule: [ { cron: '0 2 * * *' } ]
  workflow_dispatch:
```

Uğursuzluqda issue açır və ya mövcud issue-ya şərh yazır.

## Diqqət

**İlk işləmədə səhv tapılacağını gözlə.** 625 model həllin heç biri avtomatik
yoxlanmayıb — bir neçəsinin çıxışı gözlənilənlə uyğun gəlməyə bilər. Tapılanları
ayrıca issue kimi qeyd et, `az` məzmununda düzəlt, sonra tərcüməyə başla.

Kod nümunələri `java` konfiqurasiyası ilə icra olunur (`confType: "java"`) —
Android API-dən istifadə edən nümunələr (əgər varsa) işləməyəcək; onları
`"skipRun": true` bayrağı ilə istisna et.

## Tətbiq qeydi (2026-09-24)

**Nə yoxlanılır.** Dərslərin `fun main`-li kotlin blokları (92; `output`
varsa çıxış müqayisə olunur, yoxdursa yalnız xətasız işləməlidir), 625
model həll (`hell` → `gozlenilen`) və 10 meydan nümunəsi. `fun main`-siz
52 blok dərsdəki fraqmentdir — atlanır. Nəzəri çalışma və quiz kodu da
fraqmentdir. Eyni kod (overlay kodu dəyişmir) dillər arasında bir dəfə
göndərilir. Versiya seçimi `KompilyatorVersiyalari.sec` ilə eynidir
(`libs.versions.toml`-dakı Kotlin → eyni minor → `latestStable`).

**Keş** `tools/.code-cache.json`-dadır (gitignore): açar SHA-1(versiya +
kod + gözlənilən). Yalnız uğurlu nəticə yazılır; kompilyator versiyası
dəyişəndə hamısı yenidən yoxlanılır. CI-da `actions/cache` saxlayır
(uğursuz run-da da). Keşsiz keçid ≈ 8 dəqiqə, sonrakılar saniyələr.

**`normallasdir` bərabərliyi.** JS-in `trimEnd`-i Kotlin-in `Char.isWhitespace`
ilə eyni deyil (U+FEFF, U+001C–U+001F fərqlidir) — sinif əl ilə qurulub.
`tools/normallasdir-hallar.json`-u həm `NormallasdirOrtaqHallarTest` (Kotlin),
həm skriptin başlanğıcındakı öz-test oxuyur; biri ayrılsa skript
şəbəkəyə çıxmadan 2 ilə dayanır (mutasiya ilə yoxlanılıb).

**İlk keçidin tapıntıları (17) və nə edildi.** Məzmun düzəlişləri saytın
iş nüsxəsində (`kotlinweb/index.html`, `js/exercises.js`) edilib, aktivlər
`build-content.js` ilə yenidən qurulub — T0.4 ilə eyni yol; sayt reposunda
commit olunmayıb.
