## Problem

Hazırda aktivlər 840 KB-dır (xam JSON). 15 dil = **≈ 12,6 MB xam mətn**.
APK-da sıxılır (JSON 4–5 dəfə sıxılır, təxminən 2,5–3 MB), amma iki risk var:

1. **Yaddaş.** `ContentRepository` parse olunmuş obyektləri keşdə saxlayır.
   Yalnız seçilmiş dil yüklənməlidir — əks halda dil dəyişdikcə keş böyüyür.
2. **Ölçü.** Hazırkı release APK ≈ 1,9 MB. 15 dil ilə 4–5 MB gözlənilir;
   büdcə qoyulmasa nəzarətsiz artar.

## Addımlar

1. **Keş sıfırlanmasını yoxla** (T3.3-də əlavə olunur). Android Studio Memory
   Profiler: 5 dəfə dil dəyiş → heap dump → `ExerciseTopic` nüsxələrinin sayı
   **25** olmalıdır (50 və ya 125 yox).

2. **CI-da ölçü hesabatı:**

```yaml
- name: APK ölçüsü
  run: |
    ./gradlew assembleRelease
    SIZE=$(stat -c%s app/build/outputs/apk/release/app-release.apk)
    echo "APK: $((SIZE/1024)) KB"
    if [ $SIZE -gt 8388608 ]; then
      echo "::error::APK 8 MB büdcəsini asdi"; exit 1
    fi
```

> Release imzası CI-da yoxdur (keystore repoda deyil) — build imzasız qalır,
> ölçü ölçməsi üçün bu kifayətdir.

3. **Ehtiyat variantlar** (büdcə aşılarsa, sıra ilə):
   - `exercises.json`-u mövzu-mövzu 25 fayla böl → yalnız açılan mövzu yüklənir
     (547 KB → ~22 KB bir mövzu üçün). Ən böyük qazanc budur.
   - Android App Bundle (AAB) + asset pack ilə dil-üzrə paylama
   - Sıxılmış format (ölçüdə qazanc, oxunaqlıqda itki — son çarə)

## Qəbul kriteriyası

- [x] Büdcə aşılmayıb — ehtiyat variant lazım olmadı

## Diqqət

`en` tam tərcümə olunandan sonra (T4.1) ölçməni təkrarla və büdcəni real rəqəmə
görə dəqiqləşdir.

## Tətbiq qeydi (2026-09-23)

- **Keş:** `AktivKesi` (daxili sinif) `DilKesi<T>`-ə çıxdı — `dil` və `yukle`
  parametrlə gəlir, testdə Context-siz yoxlanılır. Tək yer: dəyər oxunduğu
  dillə saxlanılır, dil fərqlidirsə yenidən yüklənir və köhnəsi buraxılır.
  `DilKesiTest`: 5 dil dəyişməsi → 5 yükləmə, köhnə dilə qayıtmaq da yenidən
  yükləyir (yəni ikinci dil saxlanılmır); eyni anda 5 müraciət → 1 yükləmə.
  ViewModel-lər də (`AppViewModel`, `SearchViewModel`…) dil dəyişəndə dəyəri
  əvəz edir, köhnəsini saxlamır.
- **CI:** `tools/apk-budcesi.js` — zip kataloqunu oxuyur (asılılıqsız),
  hissələr üzrə sıxılmış/xam ölçü, dil başına orta və 15 dil proqnozu
  (latın olmayan əlifba üçün ×1,3). APK > 8 MB → çıxış 2. Hesabat
  `GITHUB_STEP_SUMMARY`-yə də yazılır. CI-da APK imzasızdır (`*-unsigned.apk`),
  skript qovluqdakı ilk APK-nı götürür.
- **Ölçü (2026-09-23, release, yalnız az):**

  ```
  dex                1 610,6 KB
  res                  550,9 KB
  assets/content/az    178,8 KB   (xam 740,9 KB)
  META-INF + lib + digər  ≈ 101 KB
  APK                2 570,8 KB
  15 dil proqnozu    ≈ 5 824 KB   (büdcə 8 192 KB)
  ```

  T3.5-dən sonra `search.json` yoxdur (dil başına ≈ 42 KB sıxılmış qənaət);
  T4.7 yarımçıq dilləri release-ə buraxmır. `en` tam tərcümə olunandan sonra
  (T4.1) ölçməni təkrarla.
