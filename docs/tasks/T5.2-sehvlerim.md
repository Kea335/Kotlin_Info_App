## Məqsəd

Səhv cavab verilən sualı təkrar öyrənmə dövrünə qaytarmaq — hazırda səhv cavab
heç yerdə saxlanılmır, istifadəçi nəyi bilmədiyini unudur.

## Məntiq

1. **Yazılma.** Səhv cavab hər iki yerdən gəlir:
   - Bilik testi (`QuizViewModel`, T2.3-də toplanır)
   - Nəzəri çalışma (`ExerciseViewModel`)

   `sehvQeydEt(sualId)`: `say++`, `ardicilDuzgun = 0`, `sonTarix = now`.

2. **Mənimsəmə.** Həmin sual sonradan düzgün cavablandırılsa `ardicilDuzgun++`.
   **2-yə çatanda** sual siyahıdan çıxır (sətir silinmir — statistika üçün qalır,
   sadəcə `mastered` sayılır).

3. **Göstərmə.** Sual mətni **seçilmiş dilin məzmunundan** götürülür (ID ilə) —
   yəni səhvlər dil dəyişəndə itmir və tərcümə olunmuş halda görünür.
   ID artıq məzmunda yoxdursa sətir səssizcə atlanır.

## Ekran

Yeni route: `Sehvlerim`. Giriş nöqtələri:
- Tənzimləmələr → «Tərəqqi» bölməsində sətir (`12 səhv sual`)
- Test nəticə ekranında düymə: «Səhvlərə bax»

Məzmun:
- Siyahı: sual mətni (ilk sətir), mövzu, neçə dəfə səhv, son tarix
- Toxunuş → sual açılır, variantlar, izah
- Yuxarıda düymə: **«Yalnız səhvlərdən test»** → `QuizViewModel` bu hovuzla
  başlayır (mövcud tur məntiqi, yeni hovuz)
- Boş hal: «Hələ səhvin yoxdur — testdən keç, səhvlər burada toplanacaq»

## Qəbul kriteriyası

- [x] Testdə və nəzəri çalışmada verilən səhv cavab Room-a yazılır
- [x] Eyni sual təkrar səhv veriləndə `say` artır
- [x] İki ardıcıl düzgün cavabdan sonra sual siyahıdan çıxır
- [x] «Yalnız səhvlərdən test» işləyir və nəticəni yazır (quiz_turu; rekord yox)
- [x] Dil dəyişəndə səhvlər itmir, yeni dildə görünür
- [x] Boş hal ekranı var («Səhvlərim» və səhv testi üçün eyni)
- [x] Ekran mətnləri resources-dadır (T3.4 qaydası)
- [x] Məntiq (`mastered` qaydası) saf funksiyada və testlidir (`sehvYenile`, T5.1)

## Diqqət

Quiz hovuzundakı sual ID-ləri iki mənbədən gəlir: `quiz.json` (`quiz-01`) və
çalışma bankı (`q-sintaksis-n-01`, `hovuzlariQur`-dakı önlüklə). «Səhvlərim»
hər ikisini eyni cədvəldə saxlayır — göstərəndə önlüyə görə hansı mənbədən
oxunacağını müəyyən et.

Nəzəri çalışmadakı səhv cavab hazırda **heç bir iz buraxmır** (yalnız düzgün
cavab `hellEdilmis`-ə yazılır) — bu taskda əlavə olunur.

## Tətbiq qeydi (2026-09-23)

- **Yazılma:** `QuizViewModel.cavabla` hər cavabı `oyrenme.cavabYaz(id, duzgun)`
  ilə yazır (T2.3-dəki yaddaşdakı `_sehvler` siyahısı silindi); tur bitəndə
  `quizTuruYaz`. `ExerciseViewModel.nezeriCavab` — nəzəri çalışmanın cavabı
  (əvvəl səhv heç iz buraxmırdı); id `bankSualId(n)` = `q-<n>`, testdəki ilə
  eyni sətir. Qayda T5.1-in `sehvYenile()`-sidir.
- **Səhv testi:** `QuizRejimi.SEHVLER` — seçim ekranında və rekordlarda yoxdur
  (`QuizRejimi.SECIM`). Hovuz id-ləri tam (qarışıq) hovuzdandır, tur aktiv
  səhvlərdən seçilir: tur gedərkən sual mənimsənilsə də turdan düşmür, indeks
  sürüşmür. Səhv yoxdursa `sehvYoxdur` → boş hal. Rekord yazılmır, `quiz_turu`
  yazılır. Route `Yol.SehvTesti` eyni `QuizScreen`-i `sabitRejim` ilə açır;
  «geri» ekranı bağlayır.
- **Ekran:** `Yol.Sehvlerim` — say, izah, «Yalnız səhvlərdən test», siyahı
  (sual, mövzu · neçə dəfə · son tarix); toxunanda kod, variantlar (düzgün
  işarəli) və izah açılır. Sual mətni seçilmiş dilin məzmunundan id ilə
  (`sualXeritesi`, `sehvSetirleri` — saf); məzmunda olmayan id atlanır.
- **Giriş nöqtələri:** Tənzimləmələr → Tərəqqi → «Səhvlərim · N səhv sual»;
  test nəticəsində «Səhvlərə bax» (turda səhv olubsa).
- Testlər: `QuizViewModelTest` +4, `ExerciseViewModelTest` +2,
  `SehvlerimViewModelTest` 4. Cəmi 304 JVM testi yaşıl. Emulyatorda ekrana
  baxılmayıb.
