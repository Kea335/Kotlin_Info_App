# T5.2 — «Səhvlərim» bölməsi

| | |
|---|---|
| **Prioritet** | P1 |
| **Təxmin** | 2 gün |
| **Asılılıq** | T5.1, T2.3 |
| **Branch** | `feature/sehvlerim` |

## Məqsəd

Səhv cavab verilən sualı təkrar öyrənmə dövrünə qaytarmaq — hazırda səhv cavab
heç yerdə saxlanılmır, istifadəçi nəyi bilmədiyini unudur.

## Məntiq

1. **Yazılma.** Səhv cavab hər iki yerdən gəlir:
   - Bilik testi (`QuizViewModel`, T2.3-də toplanır)
   - Nəzəri çalışma (`ExerciseViewModel`)

   `sehvQeydEt(sualId)`: `say++`, `ardicilDuzgun = 0`, `sonTarix = now`.

2. **Mənimsəmə.** Həmin sual sonradan düzgün cavablandırılsa `ardicilDuzgun++`.
   **2-yə çatanda** sual siyahıdan çıxır (sətir silinmir — statistika üçün qalır,
   sadəcə `mastered` sayılır).

3. **Göstərmə.** Sual mətni **seçilmiş dilin məzmunundan** götürülür (ID ilə) —
   yəni səhvlər dil dəyişəndə itmir və tərcümə olunmuş halda görünür.
   ID artıq məzmunda yoxdursa sətir səssizcə atlanır.

## Ekran

Yeni route: `Sehvlerim`. Giriş nöqtələri:
- Tənzimləmələr → «Tərəqqi» bölməsində sətir (`12 səhv sual`)
- Test nəticə ekranında düymə: «Səhvlərə bax»

Məzmun:
- Siyahı: sual mətni (ilk sətir), mövzu, neçə dəfə səhv, son tarix
- Toxunuş → sual açılır, variantlar, izah
- Yuxarıda düymə: **«Yalnız səhvlərdən test»** → `QuizViewModel` bu hovuzla
  başlayır (mövcud tur məntiqi, yeni hovuz)
- Boş hal: «Hələ səhvin yoxdur — testdən keç, səhvlər burada toplanacaq»

## Qəbul kriteriyası

- [ ] Testdə və nəzəri çalışmada verilən səhv cavab Room-a yazılır
- [ ] Eyni sual təkrar səhv veriləndə `say` artır
- [ ] İki ardıcıl düzgün cavabdan sonra sual siyahıdan çıxır
- [ ] «Yalnız səhvlərdən test» işləyir və nəticəni yazır
- [ ] Dil dəyişəndə səhvlər itmir, yeni dildə görünür
- [ ] Boş hal ekranı var
- [ ] Ekran mətnləri resources-dadır (T3.4 qaydası)
- [ ] Məntiq (`mastered` qaydası) saf funksiyada və testlidir

## Diqqət

Quiz hovuzundakı sual ID-ləri iki mənbədən gəlir: `quiz.json` (`quiz-01`) və
çalışma bankı (`q-sintaksis-n-01`, `hovuzlariQur`-dakı önlüklə). «Səhvlərim»
hər ikisini eyni cədvəldə saxlayır — göstərəndə önlüyə görə hansı mənbədən
oxunacağını müəyyən et.

Nəzəri çalışmadakı səhv cavab hazırda **heç bir iz buraxmır** (yalnız düzgün
cavab `hellEdilmis`-ə yazılır) — bu taskda əlavə olunur.
