## Məqsəd

840 KB JSON aktivinin modellərlə uyğunluğunu və bütövlüyünü hər build-də
yoxlamaq. Hazırda aktiv pozulsa bunu yalnız cihazda, «Məzmun yüklənmədi»
ekranında görmək olur.

## Qurulum

T1.1-də əlavə olunan sətir aktivləri test classpath-ına qoyur:

```kotlin
getByName("test") { resources.srcDir("src/main/assets") }
```

Testdə:

```kotlin
private fun aktiv(ad: String): String =
    checkNotNull(javaClass.classLoader?.getResourceAsStream(ad)) { "$ad tapılmadı" }
        .bufferedReader().use { it.readText() }
```

`Json` konfiqurasiyası `ContentRepository`-dəki ilə **eyni** olmalıdır
(`ignoreUnknownKeys = true`, `isLenient = true`), yoxsa test real davranışı
yoxlamır.

## Yazılacaq testlər — `data/AktivTest.kt`

### Decode
- 5 aktivin hamısı istisna atmadan decode olunur:
  `content.json`, `exercises.json`, `quiz.json`, `playground.json`, `search.json`

### Struktur sabitləri (hazırkı vəziyyət)
- 32 bölmə, `index` sahələri 0..31 və siyahıdakı mövqe ilə eynidir
- 25 mövzu, 625 nəzəri + 625 praktiki çalışma
- 15 quiz sualı, 10 playground nümunəsi, 32 axtarış sənədi

### Bütövlük
- Bütün çalışma və quiz id-ləri unikaldır (nəzəri + praktiki birlikdə)
- Hər nəzəri sual və quiz sualı üçün `opts.size == 4` və `a in 0 until 4`
- Hər praktiki çalışmada `tapsiriq`, `starter`, `hell`, `gozlenilen` boş deyil
- **`starter.trim() != hell.trim()`** (T0.4 reqressiyası)
- Hər `ExerciseTopic.sectionId` üçün `content.json`-da bölmə var
- `special` bölmələri mövcuddur: `kod-meydani`, `calismalar`, `quiz`
- Axtarış sənədlərinin id-ləri bölmə id-ləri ilə üst-üstə düşür

### Dözümlülük
- Zədəli JSON (`"{"`) decode ediləndə istisna atılır və **tutulur** —
  `AppViewModel.init` blokundakı `try/catch` yolu ilə eyni davranış
- Boş sənəd (`{"sections":[]}`) çökmə yaratmır

## Qəbul kriteriyası

- [ ] `./gradlew test` yaşıl
- [ ] Hər 5 aktiv decode testi var
- [ ] Sayılar dəyişsə test qırmızı olur (yəni sabitlər testdə yazılıb)
- [ ] T0.4 qaydası həm `verify-content.js`-də, həm JVM testində var

## Diqqət

Sayılar (32 / 625 / 15) **bilərəkdən sabit** yazılır: məzmun boru xətti səhvən
bölmə itirsə test dərhal xəbər verir. Məzmun genişlənəndə sayı yeniləmək
normaldır — əsas odur ki, itki səssiz qalmasın.
